Project Overview

Community Services Initiative • SDG 11: Sustainable Cities

The Public Transport Information Website is a static, zero-latency transit directory built for commuters across Greater Noida. Designed to operate reliably without requiring live data feeds, it provides clear, accessible daily bus timetables connecting Alpha, Beta, Gamma, and Delta sectors.
